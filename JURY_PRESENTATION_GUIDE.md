## 🚨 Troubleshooting

### Demo button not appearing?
- Refresh the page
- Complete the onboarding first
- Check bottom-right corner of screen

### No voice narration?
- Check computer volume
- Browser might block text-to-speech on first load
- Click "Voice On" button in demo controls

### Charts not updating?
- Run at least one query first
- Navigate to Telemetry tab in right panel
- Ensure result has completed (not running)

### Live processing not showing?
- Submit a query (it only appears during analysis)
- Check bottom-right area of screen
- May need to scroll if screen is small
