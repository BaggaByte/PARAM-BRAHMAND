## 🌌 Overview

**PARAM-BRAHMAND (विश्वरूप-AI)** is an end-to-end, physics-grounded Earth Intelligence Operating System engineered to ingest, process, calibrate, and interrogate heterogeneous remote sensing telemetry (Optical, Polarimetric SAR, Thermal, Hyperspectral, and DEM) via natural language and 22-language vernacular voice queries.

Traditional vision-language models hallucinate physical impossibilities—predicting standing water on 45° mountain slopes, non-conservative albedo changes, or violations of electromagnetic scattering laws. **PARAM-BRAHMAND replaces unconstrained black-box inference with deterministic physics priors, spatial conformal calibration, and linear-complexity spatial state-space modeling.**

## ⚡ Core Innovations & Features

### 1. 128-D Invariant Physics Manifold (Prakriti-Veda)
- **Yamaguchi AG4U SAR Decomposition:** Decomposes multi-pol SAR covariance into surface, double-bounce, volume, and helix scattering powers with Stokes energy conservation ($\sum P_i = P_{\text{total}}$).
- **PolInSAR RVoG Inversion:** Random Volume over Ground model inverting interferometric coherence and phase to reconstruct true 3D forest canopy heights ($z_v$).
- **MESMA Endmember Inversion:** Multiple Endmember Spectral Mixture Analysis resolving sub-pixel water, vegetation, soil, and impervious fractional covers.
- **16 Invariant Indices:** NDVI, NDWI, MNDWI, NDBI, SAVI, EVI, BSI, NDSI, SAR-NDPI, etc.

### 2. Geo-Mamba 3.0 Linear Backbone
- Replaces quadratic $\mathcal{O}(N^2)$ self-attention with $\mathcal{O}(L)$ selective state-space sequence modeling.
- Native multi-scale spatial processing capable of processing massive gigapixel Cloud-Optimized GeoTIFF (COG) scenes without tile boundary artifacts.

### 3. Navagraha 9-Agent Ensemble
| Agent | Sanskrit Name | Mission Scope |
|---|---|---|
| Optical Analysis | **Bhoomi-Optical** | High-resolution multispectral feature classification |
| SAR / InSAR Radar | **Kaal-Radar** | All-weather, cloud-penetrating radar & interferometry |
| Image Captioning | **Surya-Caption** | Physics-grounded visual telemetry description |
| Visual Grounding | **Sparsh-Grounding** | Sub-meter text-to-pixel localization & segmentation |
| Change Detection | **Samay-Change** | Bi-temporal invariant difference mapping |
| Causal Disambiguation | **Vivek-Causal** | Pearl Structural Causal Models (SCMs) |
| 4D Spatiotemporal | **Kala-Chakra-4D** | Trajectory & velocity vector modeling |
| Disaster Mitigation | **Bhoomi-Rakshak** | NDMA SOP rapid emergency routing & assessment |
| Sub-surface Mineral | **Ratna-Garbha** | Hyperspectral spectral angle mapper (SAM) |

### 4. GeoCP-v2 Spatial Conformal Calibration
- Guarantees $(1 - \alpha)$ distribution-free marginal coverage error bounds.
- Incorporates Moran's I spatial autocorrelation coefficient to dynamically adjust prediction interval widths across heterogeneous geomorphic zones.

### 5. Dharma-Chakra Hard Physics Firewall
- **Stokes Conservation:** Rejects any decomposition where $\left|\sum P_i - P_{\text{total}}\right| > 10^{-4}$.
- **Hydrodynamic Slope Consistency:** Disallows flood or standing water identification on terrain with slope gradient $> 5^\circ$ unless bounded by natural depression basins.
- **Albedo & Emissivity Consistency:** Verifies radiant energy balance against thermodynamic Stefan-Boltzmann boundaries.

## ⚡ Quickstart Guide

### 1. Prerequisites
- **Node.js** >= 20.x (Recommended: Node 22.x)
- **Python** >= 3.10
- **Git**

### 2. Clone & Setup
```bash
git clone https://github.com/BaggaByte/PARAM-BRAHMAND.git
cd PARAM-BRAHMAND
```

### 3. Python Backend & Test Verification

```bash
# Optional: create a virtual environment
python -m venv .venv
# On Windows: .venv\Scripts\activate
# On Linux/macOS: source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the complete test suite (41/41 tests)
python run_tests.py
```

### 4. Run the Master System Demonstration

Execute the self-contained pipeline demonstration showcasing all 7 layers, sensor engines, benchmark suite, and mission queries:

```bash
# Verify all 15 core modules
python param_brahmand_complete_system.py --check

# Run full live multi-layer mission demo
python param_brahmand_complete_system.py
```

### 5. Launch the FastAPI Backend Server

```bash
uvicorn param_brahmand.api.server:app --host 0.0.0.0 --port 8000 --reload
```
API Documentation will be live at: `http://localhost:8000/docs`

### 6. Launch the Interactive Frontend Console

```bash
# Install frontend dependencies
npm install

# Start Vite development server
npm run dev
```
Open **`http://localhost:8080`** in your browser.

To build the production bundle:
```bash
npm run build
```
